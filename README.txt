PetVora PawTag - how to update

1. Open your GitHub repository -> delete the old files -> upload ALL files from this folder
   (package.json, netlify.toml, the "public" folder and the "netlify" folder).
2. Netlify deploys by itself after GitHub updates.
3. Open https://pawtag-2k26.netlify.app and create a new Dog ID.

Do NOT rename the Netlify site and do NOT delete it. QR codes use that address.
